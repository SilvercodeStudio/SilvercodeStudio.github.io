About

One person, a few apps.

I'm Preston Landers. I've been an enterprise software engineer for a long time. Silvercode Studio is where I build the Mac apps I want for my own use, and share them.

Every app is free, and its code is open source on GitHub. Questions and bug reports go to each app's GitHub issues; anything else to hello@silvercode.studio.
